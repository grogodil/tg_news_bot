# News-Telegram-bot

## Файлы проекта

1. В директории `internal` находятся пакеты `db` (в нем реализована работа с БД для сохранения уникальности новостей), `newssummary` (пакет, в котором реализован парсинг RSS-леннты и формирование сообщения для telegram-бота) и `tgbot` (в этом пакете реализована логика telegram-бота)

## Описание проекта

Этот проект представляет telegram-бота, который в чат с ним присылает 1 раз в час 1 неповторяющуюся новость с Хабр по Go. В сообщении содержится заголовок новости, ссылка на новость и краткое описание новости.  HTML-теги из сообщения удалены.

## Инструкция по запуску кода локально
1. Убедитесь, что у вас установлен Go версии 1.23 или выше.
2. Установите зависимости:
   ```bash
   go mod tidy
   ```
3. Создайте файл `.env` в корне проекта и добавьте в него следующие переменные:
   ```
   TELEGRAM_BOT_TOKEN=токе_для_вашего_бота (его нужно получить в Telegram у @BotFather)
   TODO_DBFILE=путь_к_базе_данных
   ```
4. Запустите Telegram-бота:
   ```bash
   go run main.go
   ```
5. Откройте диалог с ботом, введите /start. также можо ввести команду /help, которая выведет все доступные команды.

## Инструкция по сборке и запуску проекта через Docker

1. docker build --tag my_app:v1 . 

2. docker run -d -p 7540:7540 my_app:v1 

3. Telegram-бот запущен
